# Partner — 你的私人智能助手

从零搭建的独立智能体:

- **底层模型**:DeepSeek(`deepseek-chat`),OpenAI 兼容接口,换其他平台只需改 `.env`
- **形态**:手机/电脑浏览器直接访问的网页聊天(手机端优先设计)
- **记忆**:双层记忆系统 —— 公有记忆(可分享的一般信息)+ 私有记忆(密码、客户隐私等敏感信息)
- **动手能力**:能查目录、读文件、写文件、执行命令,多步骤连续干活;写文件和跑命令每次都要你点「允许」
- **文件与图片**:能读 PDF / Word / Excel / 文本;能"看"图片(OCR 识别文字);手机端点 🖼 拍照或选图直接发给它

## 目录结构

```
partner/
├── app.py              # 服务入口(FastAPI,托管前端)
├── core/
│   ├── config.py       # 读取 .env 配置
│   ├── memory_store.py # 双层记忆存储
│   └── llm.py          # DeepSeek 调用 + 记忆工具 + 对话循环
├── memory/
│   ├── public/         # 公有记忆(可提交 git)
│   └── private/        # 私有记忆(绝不提交 git)
├── static/             # 手机网页前端
├── .env                # 你的 API key(不入 git)
└── start.bat           # 一键启动
```

## 快速开始

1. 安装依赖(只需一次):`D:\DevTools\Python\Miniconda3\envs\ai\python.exe -m pip install -r requirements.txt`
2. 配置密钥:编辑 `.env`,填入 `DEEPSEEK_API_KEY`(已配好,一般不用动)
3. 启动:双击 `start.bat`(自动使用 conda 的 ai 环境,无需手动激活;或 `python app.py` 前提是已激活 ai 环境)
4. 浏览器打开 `http://localhost:8000`

## 手机访问

手机和电脑连**同一个 WiFi**,手机浏览器打开 `http://电脑IP:8000`:

- 电脑上查 IP:运行 `ipconfig`,看无线网卡的 "IPv4 地址"
- 连不上:检查 Windows 防火墙是否放行 8000 端口

## 双层记忆怎么用

- 聊天时说「记住:……」,Partner 会写入记忆,并自动判断该存哪层(拿不准默认进私有)
- 说「忘记 ……」可以删除
- 网页右上角 📚 按钮可以查看/删除两层记忆
- 公有记忆 = 可分享的一般信息(偏好、业务常识);私有记忆 = 敏感信息(密码、客户隐私、财务)

## 安全与权限

- **访问密码**:服务开在局域网,打开页面必须先输入 `ACCESS_KEY`(在 `.env` 里,可自行修改),防止同一 WiFi 的别人操作你的 Partner
- `.env`(含 API key)和 `memory/private/` 都被 gitignore 保护,不要提交、不要发给别人
- 文件工具被限制在工作区白名单 `WORKSPACE_DIRS`(你的配置是整机 `C:/;D:/`,可自行增删),白名单外的路径和任何位置的 `.env` 都拒绝访问
- `write_file` / `run_command` 每次执行前,聊天界面会弹出操作详情卡片,你点「允许」才动手
- 危险命令(格式化、强制删除、关机等)一律自动拒绝
- 会话存在服务内存中,重启服务会清空(历史对话会丢,记忆不会丢)
- 如果泄露过 key,去 DeepSeek 平台重新生成一个
