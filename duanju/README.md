- [ ] 总时长 >20 分钟（首次上传新规），单集 >30 秒

- [ ] 版权材料必传：剧本创作记录、剪映工程文件、**AI 生成记录截图**（从今天起每次生成都截图存档！）

- [ ] 片头标注 **"AI辅助制作"**

- [ ] 发布方式：绑定抖音号需粉丝 >500 才能自主发布，粉丝不够走**平台发布**（不影响参赛）
- [ ] 抖音发布带双话题 `#AI短剧创作计划#` `#即梦AI创作者成长计划#`
