# 🪟 门窗效果图软件

手机优先的门窗效果图工具：3D 效果图 + 2D 立面图纸 + 自动报价单，纯前端，无需安装、无需联网（已内置 Three.js 引擎）。

## 功能

- **款式库**：平开窗（单/双/三扇、一固一开）、推拉窗（双/三轨、上亮）、固定观景窗、平开门（单/双扇）、推拉门（双/三轨）
- **✏️ 自建设计**：款式条末尾「➕ 自建设计」进入零件工具箱，自己拼装款式：
  - **零件（16 种）**：固定玻璃、平开（左/右）、上悬、下悬、内开内倒、推拉、折叠（2/4 扇）、平开门、推拉门、百叶（角度/间距/叶片宽可调）、中空百叶、格栅（竖/横/田字/菱形，根数厚度可调）、玻璃+格栅、花格（井字/菱形/十字）、防盗网（不锈钢，根数可调）、实板
  - **可调参数**：洞口宽高、型材厚度、分格（1-4 行 × 1-4 列）、每格零件及其参数、纱窗
  - 实时 3D 预览，保存后出现在款式条（存本机浏览器）
- **参数定制**：型材系列（断桥铝/塑钢/铝包木）、7 种颜色 + 自定义、5 种玻璃、纱窗、开启角度
- **3D 效果图**：室内房间 / 室外立面两种场景，触摸旋转缩放，光影渲染
- **实时尺寸标注**：3D 画面直接显示 宽/高/型材厚/墙厚 尺寸线与标签（随视角自动投影），导出效果图也带标注
- **2D 图纸**：按比例绘制分格、开启方向示意、尺寸标注、标题栏（含型材厚度），可导出高清 PNG
- **报价单**：按面积自动算价，零件（百叶/格栅/防盗网等）按格计加价，单价可在 ⚙️ 设置中修改并保存到本机，支持复制文本、导出图片、打印

## 运行方法

### 电脑上直接用（推荐测试）

双击 `start.bat`，浏览器打开 <http://localhost:8000>

### 手机访问（同一 WiFi，无需记 IP）

1. 电脑双击 `start.bat`（自动检测本机 IP 并用它打开页面）
2. 页面**右上角点「📱」**→ 屏幕显示当前地址的二维码
3. 手机连同一 WiFi，用**相机/微信扫一扫**即可打开
4. 打开后「添加到主屏幕」，以后点图标直接用，**再也不用输 IP**

> 防火墙提示时选择「允许访问」。路由器 IP 变化时重新扫一次即可（二维码自动跟随当前地址）。

### 📱 安装成手机 App（PWA）

**Android（Chrome/Edge）**：打开页面 → 右上角菜单「⋮」→ **添加到主屏幕 / 安装应用** → 桌面出现图标，点击全屏启动。

**iPhone（Safari）**：打开页面 → 底部「分享」按钮 → **添加到主屏幕** → 桌面出现图标。

> 说明：局域网 `http://` 地址下，Android 可能只添加为快捷方式（仍需浏览器）；iPhone 支持全屏独立模式。**部署到 HTTPS 托管后（见下节），两端都能获得完整体验**：全屏独立窗口 + 离线可用（Service Worker 已内置）。

### 部署到公网（完整体验）

整个 `doorwin` 文件夹是纯静态网站，可上传到任意静态托管（GitHub Pages、宝塔、Nginx、Cloudflare Pages 等），无需后端。HTTPS 托管后，手机安装 App 可获得全屏 + 离线能力，且不需要开电脑。

### 📦 安卓 APK（完全独立，无需网络/服务器）

根目录的 **`门窗效果图.apk`** 是打包好的安卓安装包：把整个软件装进手机，不需要电脑、不需要 WiFi、不需要任何地址。

**安装**：把 APK 传到手机（微信/QQ 发文件、数据线拷贝均可）→ 点击安装 → 允许「安装未知来源应用」→ 桌面出现图标。

**说明**：
- 支持 Android 8.0 及以上
- 导出图片直接保存到相册「Pictures/门窗效果图」文件夹
- 自建款式、价格设置都保存在手机本地
- 首次安装可能提示「未经验证的应用」，属自签名应用正常现象

**重新打包**：修改网页代码后，`cd android && build.bat` 即可重新生成（需 Python，构建工具链在 `D:\AI_agent\.apktools`）。

> 2026-09-29 已在真我 GT Neo 3（Android 14）真机验证：安装、启动、3D 渲染全部正常。

### 部署到公网

整个 `doorwin` 文件夹是纯静态网站，可上传到任意静态托管（GitHub Pages、宝塔、Nginx 等），无需后端。

## 目录结构

```
doorwin/
├── index.html          # 页面结构
├── css/style.css       # 手机优先样式
├── js/
│   ├── library.js      # 款式库 / 颜色 / 玻璃 / 型材数据
│   ├── models.js       # 参数化 3D 模型生成
│   ├── scene.js        # 3D 场景（室内/室外、灯光、相机）
│   ├── drawing.js      # 2D 立面图纸绘制
│   ├── quote.js        # 报价计算与报价单生成
│   ├── export.js       # 图片导出
│   └── main.js         # 主程序与界面交互
└── lib/                # Three.js 引擎（本地化，离线可用）
```

## 修改默认价格

打开页面 → 右上角 ⚙️ → 修改单价 → 自动保存到本机浏览器。

## 浏览器兼容

现代手机/电脑浏览器均可（需支持 WebGL）。建议 iOS Safari、Android Chrome/微信内置浏览器。
